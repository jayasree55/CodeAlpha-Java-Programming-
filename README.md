# 📈 Stock Trading Platform

## CodeAlpha Java Programming Internship

### Project Overview

The **Stock Trading Platform** is a console-based Java application that simulates basic stock market operations. It allows users to view market data, buy stocks, sell stocks, and manage their investment portfolio through an interactive menu-driven interface.

This project was developed as part of the **CodeAlpha Java Programming Internship** to demonstrate the use of Object-Oriented Programming concepts and efficient data structures.

---

## Features

* View available stocks and their prices
* Dynamic stock price updates
* Buy stocks
* Sell stocks
* Portfolio management
* Balance tracking
* Interactive console interface

---

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* HashMap
* Random Class
* Scanner Class

---

## OOP Concepts Implemented

* Classes and Objects
* Encapsulation
* Composition
* Method Overriding

---

## Project Structure

```
StockTradingPlatform/
│
├── Main.java

```

---

## How to Run

### Compile the project

```bash
javac *.java
```

### Run the application

```bash
java Main
```

---

## Sample Menu

```
1. View Market

```

---

## Time Complexity

| Operation         | Complexity |
| ----------------- | ---------- |
| Buy Stock         | O(1)       |
| Sell Stock        | O(1)       |
| Search Stock      | O(1)       |
| Display Market    | O(n)       |
| Display Portfolio | O(k)       |

Where:

* **n** = Number of available stocks
* **k** = Number of owned stocks

# 🏨 Hotel Reservation System (Java)

A simple console-based Hotel Reservation System built using Java.  
This project demonstrates basic Object-Oriented Programming (OOP) concepts like classes, objects, and data management using collections.

---

## 📌 Features

- Add new hotel rooms
- View available rooms
- Book a room for a customer
- Cancel existing bookings
- View all reservations

---

## 🏗️ Project Structure

HotelReservationSystem/
└── HotelReservationSystem.java

## How to Run
**1. Compile the program**
javac HotelReservationSystem.java
**2. Run the program**
