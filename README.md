# 📈 Stock Trading Platform

## CodeAlpha Java Programming Internship

### Project Overview

The **Stock Trading Platform** is a console-based Java application that simulates basic stock market operations. It allows users to view market data, buy stocks, sell stocks, and manage their investment portfolio through an interactive menu-driven interface.

This project was developed as part of the **CodeAlpha Java Programming Internship** to demonstrate the use of Object-Oriented Programming concepts and efficient data structures.

---

## Features

* View available stocks and their prices
* Dynamic stock price updates
* Buy stocks
* Sell stocks
* Portfolio management
* Balance tracking
* Interactive console interface

## Time Complexity

| Operation         | Complexity |
| ----------------- | ---------- |
| Buy Stock         | O(1)       |
| Sell Stock        | O(1)       |
| Search Stock      | O(1)       |
| Display Market    | O(n)       |
| Display Portfolio | O(k)       |

Where:

* **n** = Number of available stocks
* **k** = Number of owned stocks
